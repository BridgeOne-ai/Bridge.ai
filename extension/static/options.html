Bridge.ai

Before Bridge.ai starts

Bridge.ai does nothing on any website until you've read this and agreed.

  • What it reads: the messages typed on ChatGPT and Gemini, and the chatbot's replies. On Claude and Character.AI it only counts time; messages aren't read.
  • Where: only on this computer, by a model that runs inside the browser. Message text is never stored and never sent anywhere. Bridge.ai has no server and no account.
  • What it keeps, on this computer only: counts of feelings, interests and time spent, and the kinds of personal info it paused (for example "a phone number", never the number). Kept for up to 14 days.
  • One download: the on-device model (about 200 MB), once, from Hugging Face. Nothing about you is sent with it.
  • Child mode: messages that look risky are held back before the chatbot gets them, and a parent can approve some with a PIN. The child sees a "Protected by Bridge.ai" notice on every chat and is never watched without knowing it. A parent sees only what was held back, never the messages or feelings.

Who uses this browser?

The PIN is needed to leave Child mode and to approve sending a held-back message. It never leaves this computer.

Who uses this browser?

Set a parent PIN so Child mode can't be switched off without you.

Settings are locked

Enter the parent PIN to change Child mode's settings.

Settings

Turn Bridge.ai off

Stops all reading and checks on every chat site and deletes what Bridge.ai kept on this computer. You'll see the setup screen again to turn it back on. To remove it completely, remove the extension from Chrome.
